# V0 結果（2026-10-19）

## ビルド

- `mvn -pl forge-game -am install -DskipTests` は **成功**。所要時間は 32 秒（依存ライブラリのダウンロードを含む）。ログ: [build-v0.log](build-v0.log)
- 成果物:
  - `forge-core-2.0.15.jar` … 534 KB
  - `forge-game-2.0.15.jar` … 2.4 MB
- ビルドに Forge 本体の改修は不要だった。

## 依存ライブラリ（forge-game、compile スコープ）

全体は [deps.txt](deps.txt) を参照。

| ライブラリ | WASM 化（V2）で気にする点 |
|---|---|
| guava 33.3.1-android | `Game` / `Match` で EventBus を使っている（リフレクションによるハンドラー呼び出し） |
| commons-lang3 / commons-text | 特に問題になりそうな点はない |
| tinylog + slf4j | ログの出力先。ブラウザ向けの差し替えか無効化が必要になる見込み |
| sentry | クラッシュ報告。ブラウザでは不要なので、外すかスタブに差し替える候補 |
| jgrapht-core（+ jheaps, apfloat） | サイズ要因になる。何に使われているかは V1 で確認する |
| rssreader | ゲームルールには不要なはず。外せるか確認する |

## V1 / V2 に関わる所見

- `GameState` は **forge-game** にある（`forge/game/GameState.java`）。GUI モジュールなしで使える見込み。
- `Puzzle` / `PuzzleIO` は **forge-gui** にある（`forge/gamemodes/puzzle/`）。要件どおり参考実装として読むだけにし、依存はしない。
- リフレクションを使っている箇所: `Game`, `Match`（EventBus）、`TriggerType`, `ReplacementType`（`java.lang.reflect.Constructor`）、`StaticData`, `CardStorageReader`, `ImageKeys`, `FileUtil`。
- スレッドを使っている箇所: `forge-core` の `forge/util/ThreadUtil.java`。ゲームループがスレッドに依存しているかは V1-4 で確認する。
- カードデータ: `forge-gui/res/cardsfolder` に 33,983 ファイル、106 MB。全件ロードはモバイルには重い見込みなので、使うカードだけを読み込む方式の確認（V1-1）が重要。
- サンプル問題: `forge-gui/res/puzzle` に `.pzl` が 374 件ある。Phase 1 で流用できる。
